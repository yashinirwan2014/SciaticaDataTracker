01 / ABOUT THE PROJECT

Why I made it.

I wanted a project that uses Python–MySQL connectivity for something more practical than a list of sample student records.

The program has a text menu to add, view, update and delete a daily entry. Each date is the primary key, so the current version stores one entry per day. The summary is calculated in MySQL with COUNT, AVG and SUM.

02 / WHAT GETS SAVED

Four fields, plus a note.

The fields are kept short so the database table and the Python code stay manageable for a school project.

01 — WELLBEING

Pain rating

Record a daily rating from 0 to 10, alongside an optional note for context.

02 — STUDY

Study time

Enter the number of hours spent studying on that date.

03 — MOVEMENT

Walking breaks

Keep count of walking breaks and the total time spent walking.

03 / HOW IT WORKS

Python at the front.
MySQL underneath.

There is no web framework or external analytics library. Python collects and displays the information; MySQL handles storage, updates and the summary query.

PythonVariables, data types, loops, conditions and functions
SQLCREATE, INSERT, SELECT, UPDATE and DELETE
QueriesWHERE, ORDER BY, AVG, SUM and COUNT
ConnectivityPython–MySQL using mysql.connector
PLEASE NOTE

This is not a medical tool.

The tracker is for learning and personal record-keeping only. It cannot diagnose a condition or suggest treatment. Averages show only what has been entered; they do not establish a cause or effect. Keep private health information and database passwords out of this public repository.
